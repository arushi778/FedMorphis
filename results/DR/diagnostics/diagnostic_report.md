## 1. Executive Summary

This diagnostic audit evaluates the 20-epoch baseline run of the FedMorphis DR lesion segmentation model (`SharedUNet` on DDR lesion segmentation). The baseline achieved:
- **Validation (Epoch 16):** Dice = 0.3609, IoU = 0.2201, Sensitivity = 0.2782, Specificity = 0.9991.
- **Test Set:** Dice = 0.2769, IoU = 0.1607, Sensitivity = 0.1903, Specificity = 0.9985.

### Key Conclusions at a Glance:
1. **Measured Finding:** The model severely under-predicts lesion volume. Across the validation set, ground-truth lesions occupy **0.3220%** of all pixels (125,782 px), but the model predicts only **0.1745%** (68,169 px) at threshold 0.50—a **1.85× volume under-prediction** (Predicted/GT ratio = 0.5420).
2. **Measured Finding:** Lowering the classification threshold from 0.50 does **not** cure the low sensitivity. Sweeping the threshold down to 0.05 only raises sensitivity from 0.2782 to 0.3162 (+3.8 percentage points), while dropping precision from 0.5133 to 0.3672 and reducing Dice to 0.3398.
3. **Root Cause Analysis (Measured):** The predicted probability distribution on ground-truth lesion pixels is **severely bimodal**:
   - **65.88%** of all ground-truth lesion pixels have predicted probability $p < 0.01$ ($\text{logit} < -4.6$).
   - **91.27%** of false negative (FN) pixels have $p < 0.01$.
   - Only **4.04%** of FN pixels lie in the borderline range $[0.10, 0.50]$.
   - The model is not making borderline decisions; it is completely blind to subtle lesions (e.g., punctate microaneurysms, diffuse hemorrhages).
4. **Data Preprocessing Loss (Measured):** Downsampling full-resolution masks (up to $5184 \times 3456$) directly to $512 \times 512$ using `NEAREST` interpolation completely erases **5.18%** of all lesion connected components in the validation set, and specifically **9.47%** of all microaneurysms (246 distinct lesions vanished).
5. **Metric Formulation Nuance (Measured):** The baseline evaluates **global pooled (micro-averaged)** metrics by flattening all images into one large 1D tensor. On the validation set, Global Dice is 0.3609, whereas Macro-averaged (per-image mean) Dice is 0.3191.

## 3. Metric Implementation and Aggregation Audit

We examined `compute_metrics` in `src/train_dr_segmentation.py` (lines 109–142) and `src/evaluate_dr_segmentation.py` (lines 34–65).

### 3.1 Aggregation Strategy: Global (Micro-Pooled) vs Macro (Mean Per-Image)
In `train_dr_segmentation.py`:
```python
all_logits = torch.cat(all_logits, dim=0)    # [149, 1, 512, 512]
all_targets = torch.cat(all_targets, dim=0)  # [149, 1, 512, 512]
metrics = compute_metrics(all_logits, all_targets, threshold=CFG["threshold"])
```
Inside `compute_metrics`:
```python
preds_flat = preds.view(-1)
targets_flat = targets.view(-1)
```
- **Measured Finding:** Both training validation and test evaluation compute **dataset-wide micro-averaged (pooled) metrics**, flattening all $N \times 1 \times 512 \times 512$ pixels into one 1D vector.
- **Impact:** Images with large lesion counts (thousands of pixels) dominate the numerator and denominator of Dice and Sensitivity, while images with subtle lesions (tens or hundreds of pixels) contribute negligible weight.
- **Comparison on Validation Set (@ thr=0.5):**
  - **Global (Micro-Pooled) Dice:** `0.3609`
  - **Macro-Averaged (Mean Per-Image) Dice:** `0.3191` ($-0.0418$ lower)
  - **Global IoU:** `0.2201` vs **Macro IoU:** `0.2192`
  - **Global Sensitivity:** `0.2782` vs **Macro Sensitivity:** `0.3045`
  - **Global Specificity:** `0.9991` vs **Macro Specificity:** `0.9991`

### 3.2 Handling of Empty Masks ($Targets = 0$)
- In `compute_metrics`:
  $$\text{sensitivity} = \frac{\text{TP} + \text{smooth}}{\text{TP} + \text{FN} + \text{smooth}}$$
  If an image has no ground truth lesions ($\text{TP}=0, \text{FN}=0$), this formula evaluates to $\frac{0 + 10^{-6}}{0 + 0 + 10^{-6}} = 1.0$, regardless of whether the model predicted 0 or 10,000 false positive pixels.
  Similarly:
  $$\text{dice} = \frac{2\text{TP} + \text{smooth}}{2\text{TP} + \text{FP} + \text{FN} + \text{smooth}}$$
  If $\text{targets}=0$ and $\text{preds}=0$ ($\text{FP}=0$), Dice = 1.0. If $\text{FP} \ge 1$, Dice drops abruptly to $\approx 0.0$.
- **Audit in DDR Dataset:** In the DDR validation split, **100% of images (149/149) have non-zero lesion annotations**. Therefore, this empty-mask artifact did **not** corrupt the validation metrics of this baseline. However, the formulation remains fragile for datasets that include normal fundus images.

## 5. Data Pipeline Audit: Resizing, Aspect Ratio Distortion, and Lesion Erasure

We examined `dr_segmentation_dataset.py` for image resizing, mask resizing, mask combination, and pairing.

### 5.1 Aspect Ratio Squashing
- **Measured Finding:** Raw DDR images possess 19 distinct resolutions, ranging from $1467 \times 1472$ (1.00 square) to $5184 \times 3456$ and $2592 \times 1728$ (1.50–1.51 rectangular, 3:2 aspect ratio). The mean aspect ratio is **1.40**.
- **Resizing Implementation:**
  ```python
  pil_image = pil_image.resize(self.image_size, resample=Image.Resampling.BILINEAR)
  pil_mask = pil_mask.resize(self.image_size, resample=Image.Resampling.NEAREST)
  ```
  where `self.image_size = (512, 512)`.
- **Finding:** Images and masks are forcefully warped into a $1:1$ square without aspect ratio preservation (no letterboxing/padding). Circular fundus fields, vessels, and lesions undergo an anisotropic horizontal compression of up to $33.8\%$. While geometric correspondence between image and mask is preserved, lesion morphology is distorted.

### 5.2 Nearest-Neighbor Downsampling and Lesion Component Erasure
- **Measured Finding:** When raw masks are downsampled to $512 \times 512$ using `NEAREST` interpolation, small isolated lesions that fall between sampling grid points are eliminated completely.
- **Empirical Quantification on Validation Set (Connected Component Analysis via `scipy.ndimage.label`):**
  - Total connected lesion components in raw validation masks: **6,317**
  - Total connected lesion components surviving at $512 \times 512$: **5,990**
  - **Components completely erased by downsampling:** **327 components (5.18% erased)**
  - **Breakdown by lesion type:**
    - **Microaneurysms (MA):** 2,597 raw components $\rightarrow$ 2,351 surviving (**246 erased, 9.47% loss**)
    - **Hard Exudates (EX):** 1,960 raw components $\rightarrow$ 1,798 surviving (**162 erased, 8.27% loss**)
    - **Hemorrhages (HE) & Soft Exudates (SE):** Larger continuous patches are preserved, though fine fringes are thinned or fragmented.

### 5.3 Mask Combination and Pairing
- **Mask Combination:**
  ```python
  combined_mask = np.maximum(combined_mask, lesion_binary)
  ```
  Correctly implements the pixel-wise union across all 4 lesion types.
- **Pairing and Indexing:** `_find_label_dir` successfully detects `valid/segmentation label` vs `label`. All 149 validation images pair 1:1 with corresponding `.tif` masks with zero missing file errors.

### 6.2 Key Sweep Findings:
- The maximum Global Validation Dice occurs at $\tau = 0.45$ (**0.36094** vs **0.36085** at $\tau = 0.50$, a difference of $+0.00009$).

- **Conclusion:** The evaluation threshold of $0.50$ is **not** the primary contributor to low sensitivity.

### 6.3 Root Cause: Why Lowering Threshold Fails (Predicted Probability Bimodality)
To understand why threshold adjustment cannot recover the missed lesions, we extracted the model's continuous sigmoid output probabilities across all 125,782 ground-truth lesion pixels:

| Predicted Probability Range on GT Pixels | Pixel Count | % of GT Pixels | Interpretation |
| :---: | :---: | :---: | :--- |
| **$[0.00, 0.01)$** | **82,862 px** | **65.88%** | **Strongly suppressed: Model predicts background with extreme confidence** |
| $[0.01, 0.05)$ | 3,146 px | 2.50% | Near-zero probability |
| $[0.05, 0.10)$ | 1,112 px | 0.88% | Very low probability |
| $[0.10, 0.50)$ | 3,668 px | 2.92% | Intermediate / borderline |
| $[0.50, 0.90)$ | 4,306 px | 3.42% | Moderate confidence foreground |
| **$[0.90, 1.00]$** | **30,688 px** | **24.40%** | **Highly confident foreground lesion** |

- **Anatomy of False Negatives (FN):**
  - Out of 90,788 false negative pixels at $\tau=0.50$, **82,862 pixels (91.27%)** have $p < 0.01$.
  - **86,008 pixels (94.73%)** have $p < 0.05$.
  - Only **3,668 pixels (4.04%)** have $p \in [0.10, 0.50]$.
- **Explanation:** The model's predictions are polarized. It either detects a lesion with high confidence ($p > 0.90$, accounting for 24.4% of GT pixels), or it is completely oblivious to it ($p < 0.01$, accounting for 65.9% of GT pixels). Threshold tuning only affects the tiny $4\%$ borderline fraction.

## 7. Distinction Between Measured Findings and Hypotheses

### 7.1 Measured Findings (Verified Empirically from Data and Artifacts):
1. **Severe Lesion Under-prediction:** GT lesion area is 0.3220% of validation pixels; predicted area is 0.1745% (1.85× under-prediction).
2. **Threshold Sensitivity Invariance:** Sweeping $\tau$ from 0.50 to 0.05 yields only a +3.8% gain in sensitivity at the expense of severe precision loss.
3. **Extreme Bimodal Output Distribution:** 91.27% of false negative pixels have predicted probabilities $p < 0.01$.
4. **Resizing Component Erasure:** 5.18% of all lesion components and 9.47% of microaneurysm components in the validation set are erased during $512 \times 512$ `NEAREST` downsampling.
5. **Anisotropic Geometric Distortion:** Resizing arbitrary raw resolutions ($1.00$ to $1.51$ aspect ratio) to a fixed $512 \times 512$ square creates up to 33.8% horizontal squashing.
6. **Dataset Composition:** 100% of DDR validation images have lesions; MA is present in 88.6% of images, but HE accounts for 50.0% of total lesion volume.
7. **Metric Implementation:** `train_dr_segmentation.py` calculates dataset-level pooled (micro-averaged) metrics; macro-averaged validation Dice is 0.3191 vs pooled 0.3609.

### 7.2 Hypotheses (Requiring Future Experimental Testing):
1. **Hypothesis: Loss Function Imbalance:** The equal weighting in `combined_loss = bce + dice_loss` under extreme foreground rarity (0.32% foreground) causes BCE to heavily penalize false positives, driving logits deep into negative territory ($\text{logit} < -5$) for faint lesions. Focal loss or positive-weighted BCE ($\text{pos\_weight} \approx 10 - 20$) could prevent this over-suppression.
2. **Hypothesis: Lack of Multiscale / High-Resolution Feature Representations:** Microaneurysms and subtle hemorrhages consist of only a few pixels at $512 \times 512$. Standard U-Net max-pooling loses these spatial signals. Patch-based training (e.g., $512 \times 512$ patches extracted at native or $1024 \times 1024$ resolution) would preserve small lesions.
3. **Hypothesis: Pretrained Representations:** The baseline model was trained from scratch without MIM pretraining on DR data or vessel representations. Federated or local MIM pretraining may provide richer texture representations to resolve subtle lesions.
